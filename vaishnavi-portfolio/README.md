# Vaishnavi.5 — Portfolio

A responsive portfolio for Vaishnavi Pandey with a bold black-and-red theme, circular profile portrait, animated hero, skills/tools cards, and a draggable/auto-sliding project showcase.

## Run locally
1. Extract the ZIP.
2. Open `vaishnavi-portfolio` in VS Code.
3. Install the **Live Server** extension.
4. Right-click `index.html` → **Open with Live Server**.

You can also double-click `index.html` to open it directly in a browser.

## Publish
Upload the folder to a GitHub repository and enable GitHub Pages, or import the repository into Vercel. Keep the `assets` folder next to `index.html` and preserve all file names.
